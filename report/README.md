# LaTeX projects

This directory contains the two complete, independently buildable LaTeX
projects used for the dissertation submission.

## Dissertation

- Project: `Rodrigo_Laia_MEIC_Thesis/`
- Main source: `Rodrigo_Laia_MEIC_Thesis/main.tex`
- Build: `cd Rodrigo_Laia_MEIC_Thesis && make pdf`
- Committed reference PDF: `Rodrigo_Laia_MEIC_Thesis/build/main.pdf`

## Summary paper

- Project: `Rodrigo_Laia_Resumo_Tese/`
- Main source: `Rodrigo_Laia_Resumo_Tese/sample-acmtog.tex`
- Build: `cd Rodrigo_Laia_Resumo_Tese && make pdf`
- Committed reference PDF: `Rodrigo_Laia_Resumo_Tese/sample-acmtog.pdf`

The projects carry their own templates, bibliography files, and build
instructions. They do not depend on an Overleaf connection and can be copied or
cloned to another computer and built locally with a suitable TeX distribution.
