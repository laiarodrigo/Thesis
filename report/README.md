# Report

The active thesis source lives in:

`report/Rodrigo_Laia_MEIC_Thesis/`

That folder is the exported Overleaf project and should be treated as the
single source of truth for the report from now on.

## Where to edit

- Main entrypoint: `report/Rodrigo_Laia_MEIC_Thesis/main.tex`
- Front matter and thesis metadata: `report/Rodrigo_Laia_MEIC_Thesis/Front_Cover.tex`
- Package setup and language options: `report/Rodrigo_Laia_MEIC_Thesis/Preamble_commands.tex`
- Chapter content: `report/Rodrigo_Laia_MEIC_Thesis/Chapters/`
- Bibliography: `report/Rodrigo_Laia_MEIC_Thesis/Bibliography.bib`
- Figures: `report/Rodrigo_Laia_MEIC_Thesis/Images/`

Once the source is kept here, future revisions can be made directly against the
actual thesis text instead of reconstructing context from scratch.
